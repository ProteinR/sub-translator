# Translator Automation

Этот проект автоматизирует процесс перевода строк с использованием Google Gemini API и Playwright. Программа теперь поставляется с удобным **Web-интерфейсом**, который позволяет настраивать параметры, управлять списком ссылок, редактировать промпты и просматривать логи в реальном времени прямо в браузере.

## Предварительные требования

Для запуска проекта на macOS (или другой ОС) вам понадобятся:

1.  **Go (Golang)**: Скачайте и установите последнюю версию с [официального сайта](https://go.dev/dl/) или установите через Homebrew (для macOS):
    ```bash
    brew install go
    ```
2.  **Git**: Предустановлен на macOS, либо можно установить через Homebrew:
    ```bash
    brew install git
    ```
3.  **Google Gemini API Key**: Получите ключ API в [Google AI Studio](https://aistudio.google.com/).

## Установка

1.  **Склонируйте репозиторий** (или скачайте архив с кодом):
    ```bash
    git clone <ссылка-на-ваш-репозиторий>
    cd translator
    ```

2.  **Установите зависимости Go**:
    ```bash
    go mod tidy
    ```

3.  **Установите браузеры для Playwright**:
    Для избежания проблем совместимости версий необходимо устанавливать ту же версию, которая прописана в файле `go.mod` (на данный момент это `v0.5200.1`):
    ```bash
    cd src
    go run github.com/playwright-community/playwright-go/cmd/playwright@v0.5200.1 install --with-deps
    cd ..
    ```

## Запуск приложения (Умный старт)

Больше не нужно использовать терминал для запуска! Я создал специальное macOS приложение, которое сделает всё за вас.

Просто сделайте **двойной клик** по файлу:

> 🚀 **`Start Loka Translator.app`**

**(В первый раз macOS может попросить разрешение на запуск, так как файл скачан из интернета. Зайдите в "Системные настройки" -> "Конфиденциальность и безопасность" и разрешите запуск).**

**Что делает это приложение при двойном клике?**
1. Открывает окно терминала.
2. Проверяет наличие новых версий проекта на GitHub (через `git pull`).
3. Если есть обновления (или проект запускается впервые) — автоматически скачивает их и компилирует новую версию.
4. Автоматически создает файлы с промптами (`prompt_to_PL.txt` и т.д.), если их нет.
5. Запускает проект и открывает веб-интерфейс в вашем браузере по адресу: **`http://localhost:8080`**.

*Примечание: Если вы используете Linux или Windows (WSL), вы по-прежнему можете запустить программу через терминал: `./src/start.sh`.*

### Как проверить обновление

Номер работающей версии отображается рядом с названием **Loka Translator Control Panel** и в журнале при запуске. Текущая версия: **1.5.1**.

Автообновление работает при запуске через `Start Loka Translator.app` или `src/start.sh`: запускается `git pull`, затем сборка. Изменения должны быть предварительно отправлены в GitHub; локальные правки с другого компьютера не скачиваются. Нужны доступ к репозиторию, интернет и успешная сборка. Если загрузка не удалась, запускается локальная версия с предупреждением в терминале. Прямой запуск `translator-web` не проверяет обновления. Перед обновлением закройте ранее запущенное приложение, затем запустите его через ярлык и проверьте номер версии.

## Как пользоваться Web-интерфейсом

1. Направление определяется автоматически из страницы Lokalise: базовая языковая строка — исходник, остальные видимые языковые строки — цели перевода. Ручного выбора языка в приложении нет.
2. В **API Settings** укажите ключ Gemini и модель.
3. В **Projects to Translate** добавьте ссылки Lokalise. Поддерживаются страницы с несколькими документами; параметр `files_selection` сохраняется, вид автоматически устанавливается в **Multilingual**. В Lokalise должны быть видны исходный и все нужные целевые языки.
4. В **Gemini Prompt** редактируйте общие правила стиля и качества. Направление перевода добавляется автоматически к каждому запросу. Настройки сохраняются в `data/config.json`; прежние языковые промпты сохранены в поле `prompts`, но автоматический режим использует общий `translationPrompt`.
5. Нажмите **Start Translation**. Каждый проект обрабатывается по всем обнаруженным языкам; строки разных документов отправляются отдельно. Названия берутся из заголовков `.project-document__file-name` и атрибута строки `data-filename`.
6. По умолчанию заполняются только пустые переводы. **Перезапись всех переводов** разрешает замену заполненных целевых ячеек; исходник не изменяется.
7. Проект удаляется из очереди только после успешной обработки всех обнаруженных языков. При ошибке остаётся в списке; повторный запуск пропускает уже заполненные ячейки. **Stop** останавливает обработку после текущего шага.

### Проверка изменений

Из папки `src` выполните `go test ./...`. Для проверки парсера на сохранённом HTML Multilingual: `LOKALISE_HTML_FIXTURE=/absolute/path/page.html go test -v ./...` (нужны установленные Playwright и Chromium). Проверка использует локальный HTML, сетевые запросы страницы блокируются.

### Авторизация (Первый запуск)
*   При первом запуске процесса перевода (когда вы нажмете Start), автоматически откроется окно браузера (Playwright) со страницей входа на платформу.
*   **Введите логин и пароль вручную** в открывшемся браузере.
*   Если потребуется капча или 2FA, пройдите их.
*   Как только вы войдете в систему и заголовок "Log in" исчезнет, программа **автоматически** сохранит вашу сессию (файл `auth.json`) и продолжит работу. При следующих запусках вход будет выполнен автоматически.

## Возможные проблемы

*   **Порт 8080 занят**: Если веб-интерфейс не открывается, возможно, порт `8080` уже используется другой программой. Вы можете изменить порт в файле `main.go` (переменная `port := ":8080"`).
*   **Ошибка "playwright not found"**: Убедитесь, что вы выполнили шаг 3 из раздела "Установка".
*   **Ошибки перевода**: Проверьте лимиты вашего API ключа Gemini или убедитесь, что страница успевает загружаться (можно увеличить задержки в интерфейсе).

### Решение проблем с обновлениями (Git)
Если приложение не видит новые изменения (например, зависает на старой версии) или если вы получаете ошибку при загрузке обновлений (Git конфликты), вы можете обновить проект вручную:
1. Откройте приложение **Терминал** (Terminal.app).
2. Перейдите в папку с проектом. Для этого введите `cd ` (с пробелом на конце) и перетащите папку проекта в окно терминала, затем нажмите `Enter`.
3. Выполните следующие команды для сброса всех локальных изменений и жесткого обновления:
   ```bash
   git fetch origin
   git reset --hard origin/main
   git pull
   ```
4. После этого просто запустите проект как обычно (двойной клик по `Start Loka Translator.app` или `./src/start.sh`) — он автоматически пересобирётся с новыми изменениями.

## Структура проекта

*   `Start Loka Translator.app`: macOS-приложение для удобного запуска двойным кликом.
*   `src/`: Папка с исходным кодом (Go, HTML, скрипт запуска и бинарный файл).
*   `data/`: Папка, в которой автоматически сохраняются все ваши настройки, логи, промпты и сессии (`.env`, `auth.json`, `projects.txt`). Создается при первом запуске.
