# Translator Automation

Этот проект автоматизирует процесс перевода строк с использованием Google Gemini API и Playwright. Программа теперь поставляется с удобным **Web-интерфейсом**, который позволяет настраивать параметры, управлять списком ссылок, редактировать промпты и просматривать логи в реальном времени прямо в браузере.

## Предварительные требования

Для запуска проекта на macOS (или другой ОС) вам понадобятся:

1.  **Go (Golang)**: Скачайте и установите последнюю версию с [официального сайта](https://go.dev/dl/) или установите через Homebrew (для macOS):
    ```bash
    brew install go
    ```
2.  **Git**: Предустановлен на macOS, либо можно установить через Homebrew:
    ```bash
    brew install git
    ```
3.  **Google Gemini API Key**: Получите ключ API в [Google AI Studio](https://aistudio.google.com/).

## Установка

1.  **Склонируйте репозиторий** (или скачайте архив с кодом):
    ```bash
    git clone <ссылка-на-ваш-репозиторий>
    cd translator
    ```

2.  **Установите зависимости Go**:
    ```bash
    go mod tidy
    ```

3.  **Установите браузеры для Playwright**:
    Для избежания проблем совместимости версий необходимо устанавливать ту же версию, которая прописана в файле `go.mod` (на данный момент это `v0.5200.1`):
    ```bash
    go run github.com/playwright-community/playwright-go/cmd/playwright@v0.5200.1 install --with-deps
    ```

4.  **Создайте базовый файл конфигурации**:
    Скопируйте файл `.env-example` и назовите его `.env`. (В дальнейшем его можно будет редактировать через веб-интерфейс).
    ```bash
    cp .env-example .env
    ```

## Запуск приложения (Умный старт)

Больше не нужно обновлять и собирать проект вручную! Я создал "Умный лаунчер", который сделает всё за вас.

Просто запустите скрипт `start.sh`:

```bash
./start.sh
```

**Что делает `start.sh`?**
1. Проверяет наличие новых версий проекта на GitHub (через `git pull`).
2. Если есть обновления (или проект запускается впервые) — автоматически компилирует новый бинарный файл.
3. Если обновлений нет — моментально запускает уже собранный проект.
4. Открывает веб-интерфейс в вашем браузере.

*(При запуске скрипт автоматически запустит локальный веб-сервер и откроет в вашем браузере вкладку с панелью управления: **`http://localhost:8080`**).*

## Как пользоваться Web-интерфейсом

1. **API Settings:** В левой панели введите ваш `GEMINI_API_KEY`, выберите `MODEL` и `TRANSLATE_TO` (язык перевода, например `PL` или `EN`). Вы также можете настроить задержки для автоматизации.
2. **Projects to Translate:** В центральной панели вставьте список URL-адресов проектов (по одному на строку).
3. **Gemini Prompt:** Здесь вы можете отредактировать промпт, который будет отправляться в нейросеть. Он автоматически сохраняется в файл `prompt_to_X.txt`.
4. **Сохранение и запуск:**
   - Нажмите **"Save Config"**, чтобы сохранить все ваши настройки (они запишутся в `.env` и другие файлы).
   - Нажмите **"Start Translation"**, чтобы запустить процесс.
5. **Логи и процесс:**
   - Справа вы увидите терминал. Все логи работы программы (поиск строк, взаимодействие с браузером, отправка в Gemini) будут отображаться там в реальном времени.
   - Во время работы вы можете нажать **"Stop"**, чтобы безопасно прервать выполнение (остановится после завершения текущего шага).

### Авторизация (Первый запуск)
*   При первом запуске процесса перевода (когда вы нажмете Start), автоматически откроется окно браузера (Playwright) со страницей входа на платформу.
*   **Введите логин и пароль вручную** в открывшемся браузере.
*   Если потребуется капча или 2FA, пройдите их.
*   Как только вы войдете в систему и заголовок "Log in" исчезнет, программа **автоматически** сохранит вашу сессию (файл `auth.json`) и продолжит работу. При следующих запусках вход будет выполнен автоматически.

## Возможные проблемы

*   **Порт 8080 занят**: Если веб-интерфейс не открывается, возможно, порт `8080` уже используется другой программой. Вы можете изменить порт в файле `main.go` (переменная `port := ":8080"`).
*   **Ошибка "playwright not found"**: Убедитесь, что вы выполнили шаг 3 из раздела "Установка".
*   **Ошибки перевода**: Проверьте лимиты вашего API ключа Gemini или убедитесь, что страница успевает загружаться (можно увеличить задержки в интерфейсе).

## Структура проекта

*   `main.go`: Основной код программы и веб-сервера.
*   `index.html`: Код графического интерфейса (встроен в бинарник).
*   `.env`: Ваши секретные настройки (теперь обновляется через UI).
*   `projects.txt`: Список ссылок для обработки.
*   `prompt_to_PL.txt` / `prompt_to_EN.txt`: Файлы промптов.
*   `auth.json`: Файл сессии (создается автоматически).
